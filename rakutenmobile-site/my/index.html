မိတ်ဆက်လင့်ခ်ဖွင့်ခြင်းမှ ဝန်ဆောင်မှုစတင်အသုံးပြုခြင်းအထိ အရေးကြီးသောအဆင့်များကို စစ်ဆေးပါ။

မိတ်ဆက်လင့်ခ်မှ တရားဝင်စာမျက်နှာကိုဖွင့်ပါ

အကျိုးခံစားခွင့်၊ အရည်အချင်းနှင့် နောက်ဆုံးရက်များ ပြောင်းလဲနိုင်ပါသည်။ Rakuten Mobile တရားဝင်စာမျက်နှာတွင် နောက်ဆုံးအချက်အလက်ကို စစ်ဆေးပါ။

HOW TO APPLY

အဆင့် ၃ ဆင့်

  1. 01

    မိတ်ဆက်လင့်ခ်ကိုဖွင့်ပါ

    တရားဝင်အစီအစဉ်စာမျက်နှာသို့သွားပြီး Rakuten ID ဖြင့် ဝင်ရောက်ပါ။

  2. 02

    စည်းကမ်းချက်များစစ်ပြီး လျှောက်ထားပါ

    MNP သို့မဟုတ် နံပါတ်အသစ်ကိုရွေးပြီး လက်ရှိအစီအစဉ်နှင့် နောက်ဆုံးရက် သတ်မှတ်ချက်များကို စစ်ဆေးပါ။

  3. 03

    စတင်အသုံးပြုရန် သတ်မှတ်ချက်များပြီးစီးပါ

    သတ်မှတ်ရက်အတွင်း စတင်အသုံးပြုခြင်းနှင့် Rakuten Link အသုံးပြုခြင်းတို့ ပါဝင်နိုင်သည့် တရားဝင်သတ်မှတ်ချက်အားလုံးကို ပြီးစီးပါ။

BEFORE YOU START

ကြိုတင်ပြင်ဆင်ရန်

  • Rakuten ID နှင့် စကားဝှက်
  • MNP အတွက် လက်ရှိဖုန်းကုမ္ပဏီအချက်အလက်
  • ကိုယ်ရေးအထောက်အထားနှင့် ငွေပေးချေမှုနည်းလမ်း
  • တရားဝင်စာမျက်နှာရှိ နောက်ဆုံးအစီအစဉ်စည်းကမ်းချက်များ

နောက်ဆုံးတရားဝင်စည်းကမ်းချက်များကို စစ်ဆေးပါ
